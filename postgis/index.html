Por que sair do shapefile

O shapefile é formato de troca, não de operação

Shapefile

  • Limite de 2 GB por arquivo
  • Nomes de campo com 10 caracteres
  • Um único tipo de geometria
  • Sem concorrência nem integridade

Banco espacial

  • Multiusuário com controle de concorrência (ACID)
  • Restrições de integridade
  • SQL como linguagem de análise
  • Processamento no servidor e base para a web

O que é o PostGIS

Extensão espacial do PostgreSQL, padrão OGC Simple Features

Tipos de geometria

Point, LineString, Polygon e as variantes Multi

Sistemas de coordenadas

SRID 4674 para armazenar, 31982 para medir em metros

Habilitar o PostGIS

Uma extensão liga o espacial no PostgreSQL

pgAdmin · SQL

-- Habilitar a extensão espacial
CREATE EXTENSION IF NOT EXISTS postgis;

-- Conferir a instalação
SELECT PostGIS_Full_Version();

-- Representar uma geometria em texto (WKT), SRID 4674
SELECT ST_GeomFromText('POINT(-53.7430 -24.7136)', 4674);

WKT e WKB são os formatos de representação da geometria. O SRID identifica o sistema de coordenadas de cada objeto.

Tabela espacial

CREATE TABLE micropolo (
    id    serial PRIMARY KEY,
    nome  varchar(120) NOT NULL,
    geom  geometry(MultiPolygon, 4674)
);

CREATE TABLE cmei (
    id          serial PRIMARY KEY,
    nome        varchar(120) NOT NULL,

Graus erra, metros acerta

Medir em coordenadas geográficas dá resultado errado

Distância: 4674 (graus) versus 31982 (UTM 22S, metros)

SELECT
    ST_Distance(a.geom, b.geom)                       AS dist_graus,   -- não use
    ST_Distance(ST_Transform(a.geom, 31982),
                ST_Transform(b.geom, 31982))          AS dist_metros   -- correto
FROM cmei a, cmei b
WHERE a.id = 1 AND b.id = 2;

Reprojete com ST_Transform ou use o tipo geography, que trabalha em metros nativamente.
